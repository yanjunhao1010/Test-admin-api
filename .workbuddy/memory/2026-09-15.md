### 本次确认的技术事实
- AL3 用 `dnf`；MySQL 安装先探测 `dnf module list mysql`：
  - 有模块 → `dnf module enable mysql:8.0 -y && dnf install -y mysql-server`
  - 无模块 → `dnf install -y compat-openssl10`（MySQL 8 依赖旧版 OpenSSL，缺了 mysqld 起不来）
    + `dnf module disable mysql -y`（系统模块与官方源冲突）
    + `dnf install -y https://dev.mysql.com/get/mysql80-community-release-el8-7.noarch.rpm` + `mysql-community-server --nogpgcheck`
  - 注意 MySQL 官方源现在默认是 9.x，用 mysql80-community-release 包才会默认启用 8.0 子仓库
- 服务名是 `mysqld` 不是 `mysql`；临时密码在 `/var/log/mysqld.log`，
  改密码必须加 `--connect-expired-password`（临时密码处于已过期状态）
- 默认密码策略：≥8 位且含大小写 + 数字 + 特殊字符，否则 ERROR 1819

### 四个关键结论（易错点）
1. **`bind-address = 127.0.0.1`** —— MySQL 8 默认监听所有网卡；同机部署应绑本机，安全组**不放行 3306**
   （阿里云官方教程里让放行 3306 是给远程客户端直连场景的）。要用客户端连请走 SSH 隧道。
2. **账号必须同时建 `@'localhost'` 和 `@'127.0.0.1'`** —— MySQL 把前者当 Unix socket、后者当 TCP，是两套账号；
   pymysql 配 `host: 127.0.0.1` 走 TCP，只建 localhost 会报 `Access denied for user 'xxx'@'localhost'`（报错信息有迷惑性）。
3. **自建必须自己做备份** —— `/etc/cron.daily/mysql-backup` 里 mysqldump | gzip，保留 14 天；
   root 密码存 `/root/.mysql_root_pass`（600）。备份与库同盘，需另传 OSS 或他机。
4. 顺手要设 `character-set-server = utf8mb4`（否则中文变问号）和 `default-time-zone = '+08:00'`（否则时间差 8 小时）。
